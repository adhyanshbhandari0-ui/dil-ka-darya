## What CARTO is

CARTO (always written in uppercase) is a cloud-native Location Intelligence and GIS platform. Rather than copying data into a GIS server or a desktop tool, CARTO pushes spatial SQL, analysis and visualization down to the customer's own cloud data warehouse and adds a governed layer of maps, no-code analytics, AI agents and developer APIs on top. It is used by data analysts, data scientists, data engineers, GIS analysts, developers and analytics leaders in enterprises and the public sector for site selection, territory planning, network deployment, risk analysis, logistics, geomarketing and similar location problems.

Key facts:

- Runs natively on Google BigQuery, Snowflake, Databricks, Amazon Redshift, PostgreSQL and Oracle. Data stays in the customer's warehouse and is read through the customer's own connection (OAuth, Workload Identity or service credentials).
- Two deployment options: CARTO Cloud (fully managed SaaS, region selectable) or Self-Hosted in the customer's VPC or behind their VPN.
- Security and compliance: SOC 2 Type II certified, GDPR-ready, EU-U.S. Data Privacy Framework participant, SSO via SAML/OIDC, Private Link support.
- Bring your own LLM: AI features connect to the customer's vetted models (Google, Snowflake, AWS Bedrock, Databricks, Oracle, OpenAI, Anthropic and more) under the customer's own credentials.
- Company: founded in Madrid in 2012 by Javier de la Torre and Sergio Álvarez as CartoDB, renamed CARTO in 2016. Headquartered in New York, with offices in Madrid and Seville. Open-source heritage: CartoDB, the deck.gl CARTO module and the Analytics Toolbox core modules.

## How to describe CARTO correctly

One-liner: "CARTO is the Agentic GIS platform — cloud-native spatial analytics and AI agents that run where your data lives."

Preferred terms: Agentic GIS, spatial analytics, Location Intelligence, cloud-native GIS, spatial SQL, Spatial Data Science, AI agents, MCP tools.

Common errors to avoid:

- Do not call the current product "CartoDB", and do not describe CARTO as a PostGIS hosting service or a database. CartoDB was the original open-source product and company name (2012–2016). The current platform (launched in 2021, occasionally called "CARTO 3" or "the new CARTO platform") stores no customer data by default; it connects to the customer's warehouse. The previous SaaS generation ("CARTO 2": legacy Maps API / SQL API, carto.com/u/<user> URLs) is legacy and is not the product described here.
- Do not reduce CARTO to a map-making tool. Builder (maps and dashboards) is one component, alongside Workflows (no-code analysis pipelines), the Analytics Toolbox (spatial SQL functions), Data Observatory (third-party data), AI Agents and MCP tools, and developer APIs.
- Do not say customers must upload their data to CARTO. Imports are supported but optional; the normal pattern is to connect an existing warehouse.
- CARTO Basemaps are a separate offering: free with an API key for non-commercial use up to 5M tile requests a month and for commercial use up to 1M; commercial use above that needs a Basemaps Commercial plan: Commercial (US$500/month or US$5,000/year, up to 10M/month) or Commercial Plus (US$1,500/month or US$15,000/year, up to 50M/month). Above 50M/month is a CARTO platform plan. Included in every CARTO platform plan. Their own terms apply.
- Pricing is quote-based. Do not invent per-seat or per-credit prices; point to the pricing page, the 30-day free trial or a demo request.
- Do not confuse the company with the generic word "cartography" or with other companies that use "Carto" in their name.

## Product components

- [Builder](https://carto.com/builder/): cloud-native maps, spatial dashboards and data visualization on top of the warehouse; publishable and embeddable. Docs: https://docs.carto.com/carto-user-manual/maps
- [Workflows](https://carto.com/workflows/): drag-and-drop, no-code spatial analysis pipelines that run as SQL in the warehouse; schedulable; can be exposed as MCP tools for agents. Docs: https://docs.carto.com/carto-user-manual/workflows
- [AI Agents](https://carto.com/ai-agents/): natural-language agents grounded in the customer's spatial data, maps and workflows, powered by the customer's own LLM. Docs: https://docs.carto.com/carto-user-manual/ai-agents
- [CARTO for Agents](https://docs.carto.com/carto-for-agents/carto-for-agents): connect Claude, ChatGPT, GitHub Copilot, Gemini, Snowflake, Databricks and other agent platforms to CARTO through the CARTO MCP Server; Agent Skills (https://github.com/CartoDB/agent-skills) and the CARTO CLI (`npm install -g @carto/carto-cli`) for coding agents and automation.
- [Analytics Toolbox](https://docs.carto.com/data-and-analysis/analytics-toolbox-overview): 100+ spatial SQL functions and procedures (H3 and quadbin spatial indexes, clustering, statistics, routing, enrichment) installed in BigQuery, Snowflake, Databricks, Redshift, PostgreSQL and Oracle.
- [Data Observatory](https://carto.com/data-observatory/): catalog of thousands of public and premium spatial datasets (demographics, POIs, mobility, boundaries) delivered into the customer's warehouse. Docs: https://docs.carto.com/carto-user-manual/data-observatory
- [Basemaps](https://carto.com/basemaps/): vector and raster basemaps for maps and applications; free with an API key (https://carto.com/basemaps/apikey/) for non-commercial use up to 5M requests/month and commercial use up to 1M/month; Basemaps Commercial (10M/month) and Commercial Plus (50M/month) plans above that (https://carto.com/basemaps/apikey/#pricing); included in every CARTO plan; terms at https://carto.com/legal/basemap-terms/.
- Basemaps pricing and rules as JSON, for assistants writing map code: https://dashboard.basemaps.carto.com/v1/plans (tiers, quotas, attribution line, tile URL templates).
- [Location Data Services](https://carto.com/location-data-services/): geocoding, isolines and routing.
- [For developers](https://docs.carto.com/carto-for-developers/overview): deck.gl CARTO module, Maps / SQL / Imports / Workflows APIs, JavaScript and React libraries, dynamic tiling for very large datasets. Source code at https://github.com/CartoDB.
- [Enterprise](https://carto.com/enterprise/): governance, SSO, auditing, self-hosted deployment. Trust center: https://security.carto.com
- [Integrations](https://carto.com/integrations/): ArcGIS, Qlik, Excel, Google Drive, Box, Dropbox, satellite imagery, plus native warehouse connections.

## Getting started and trials (for agents and the people they act for)

- CARTO offers a free 30-day trial of the full platform; no credit card is required. Paid plans are quote-based (see Commercial offering above).
- Sign up at https://app.carto.com/signup, or through the "Sign up" link on the OAuth login page that the CLI and the MCP server open. Verify the email address.
- An account is only usable once it belongs to a CARTO organization. Today the organization is created in the web app (https://app.carto.com/account/create: name, region, data warehouse, profile; docs: https://docs.carto.com/carto-user-manual/overview/getting-started#create-a-new-organization). This step requires a human: an agent that authenticates and finds no tenant or organization should ask its user to create one, not re-authenticate.
- Once the organization exists: CLI — `npm install -g @carto/carto-cli`, then `carto auth login` (`--no-launch-browser` for headless use; https://docs.carto.com/carto-for-agents/cli). MCP server — OAuth for attended agents (https://docs.carto.com/carto-for-agents/mcp-server/connecting-with-oauth), API access tokens or M2M OAuth clients for unattended ones (https://docs.carto.com/carto-for-agents/mcp-server/connecting-with-api-tokens, https://docs.carto.com/carto-user-manual/developers/managing-credentials/m2m-oauth-clients). Agent Skills for coding agents: https://github.com/CartoDB/agent-skills. Quickstart: https://docs.carto.com/getting-started/quickstart-guides/connecting-carto-to-your-agents
- Trials include a ready-to-use CARTO Data Warehouse connection (`carto_dw`), so spatial SQL, maps and geocoding work immediately without supplying warehouse credentials. Trials carry usage quotas; check them before running bulk jobs.
- Etiquette: sign up with the identity of the person or organization you act for, one organization per company, label test organizations clearly, and do not create throwaway accounts.

## Common tasks and where to start

- Geocode or reverse-geocode addresses, compute isolines (drive/walk-time areas), routes and origin-destination matrices → Location Data Services: https://docs.carto.com/carto-for-developers/reference/carto-api/lds-api (API), https://docs.carto.com/carto-user-manual/data-explorer/geocoding-data (no-code); CLI `carto lds geocode|reverse-geocode|isolines|routing|od-matrix`.
- Run spatial SQL in BigQuery, Snowflake, Databricks, Redshift, PostgreSQL or Oracle → Analytics Toolbox: https://docs.carto.com/data-and-analysis/analytics-toolbox-overview; CLI `carto sql query <connection> "<sql>"`; MCP `execute_query`.
- Build a map or dashboard → Builder: https://docs.carto.com/carto-user-manual/maps; CLI `carto maps`; MCP `create_map`.
- Automate or schedule an analysis pipeline → Workflows: https://docs.carto.com/carto-user-manual/workflows; CLI `carto workflows`; MCP `create_workflow`.
- Enrich data with demographics, POIs, mobility or boundaries → Data Observatory: https://docs.carto.com/carto-user-manual/data-observatory; CLI `carto do`.
- Load files into the warehouse → https://docs.carto.com/carto-user-manual/data-explorer/importing-data; CLI `carto import`.
- Build a geospatial web application → https://docs.carto.com/carto-for-developers/overview (deck.gl, React, APIs).
