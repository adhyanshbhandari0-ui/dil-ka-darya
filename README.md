Original snapshots: raw_repos/. Searchable dumps: extracted_text/. Downloaded documents: downloaded_links/. PDFs: pdfs/. PDF text: pdf_text/. Links: links_index.csv and links_index.md. Provenance and checksums: provenance/. Failures: failed_links.log and extraction_errors.log. Size exclusions: large_files_skipped.log.

External links are followed one level only. Rows include links discovered on external pages; not all indexed links are fetched. Network failures, access restrictions and malformed source URLs are logged. Image-only PDFs are flagged for OCR. Upstream licenses and notices remain in source folders; no additional rights are granted.

On your Mac:

```sh
git clone https://github.com/adhyanshbhandari0-ui/dil-ka-darya.git ~/dil-ka-darya
python3 ~/dil-ka-darya/restore_text_dumps.py
```

Files over 95 MB are excluded from Git. Oversized text dumps can be reconstructed exactly from their committed parts.
